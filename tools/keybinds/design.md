# Пресет управления Escape The End

Проверенная база — Rainline 0.1, CurseForge file 9001599, Minecraft 1.20.1, Forge 47.4.10. `author-keys.txt` содержит только назначения из авторского `options.txt` с SHA-256 `3039a05e63fd95063e4c95c6f2242911237ee80a155f213e77c8e4005b9f2e7c`. Его 110 имён совпали с именами из `options.txt` существующего игрового экземпляра. В `registered-keys.txt` сохранены только имена, которые ранее записал клиент.

Основные клавиши и подсказки квестбука сохранены. R — перекат, G — квесты, H — команда, J — новая метка, C — приближение и M — карта. L открывает достижения, P — список игроков для настройки социальных взаимодействий. В творческом режиме F7 и F8 сохраняют и загружают панели быстрого доступа. Средняя кнопка мыши остаётся за выбором блока. Сортировка вынесена на `;` в контейнере. В поставляемом Inventory Sorter 23.1.9 она зарегистрирована с контекстом Forge GUI, а обработчик принимает клавиатуру в `AbstractContainerScreen`. Действия, отключённые автором, сохранены отключёнными за исключением четырёх перечисленных клавиш Minecraft.

Проверка сверяет все 110 отображаемых назначений и требует отдельную физическую клавишу для каждого назначенного действия даже при разных контекстах и модификаторах. Она покрывает записи `key_` и не проверяет жёстко заданные сочетания модов вне этой таблицы. Новый запуск клиента для приёмки не выполнялся.

```powershell
python -B tools/keybinds/build_preset.py
python -B tools/keybinds/check_preset.py --author-archive $authorZip
```

При обновлении автора снова сравните список из его архива с зарегистрированными назначениями, затем проверьте базовое управление и контексты изменившихся модов. Рецепт упаковки закрепляет SHA-256 исходных настроек и пресета. После обновления данных пересчитайте рецепт и секцию `overlay` полного lock.
