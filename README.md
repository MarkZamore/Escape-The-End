# Escape The End

Rainline, выпуск 0.1. Minecraft 1.20.1, Forge 47.4.10, Java 17. На CurseForge версия представлена как «Escape The End-1.20.1.zip», имя загруженного автором файла `Escape The End-0.1.zip`. Точный архив занимает 60 449 095 байт, SHA‑256 `af7be8b4042f40f6839ada6b526803b4d4d06cee8955b2a3daead55283839294`. [Авторский выпуск CurseForge](https://www.curseforge.com/minecraft/modpacks/escape-the-end/files/9001599)

Будущая карточка занимает `minecraft-20` и использует отдельный путь `Escape The End`. Запись каталога заменяет строку Levitated одним изменением после приёмки. Без алиасов пути и источника лаунчер оставляет миры и установку Levitated в исходных папках. На выпущенном лаунчере 500 проверены раздельные папки миров и кеши источников. Если лаунчер когда-либо видел Levitated только как локальную сборку, она может остаться в локальном списке.

## Подготовка на стенде

Получите официальный ZIP и укажите путь к нему в `$authorZip`. Запускайте из корня чистых исходников LANMinecraft. `$stage` — новый каталог внутри принадлежащего задаче `artifacts/agent-runs/<task-id>` с `RUN.json`.

```powershell
python tools/workspace_storage.py --check
python -B tools/PackData/CurseForge/prepare.py --project-id 1712767 --file-id 9001599 --client-archive $authorZip --expect LocalSources/Escape-The-End/tools/upstream-lock.json --java-major 17 --placements LocalSources/Escape-The-End/tools/curseforge-placements.json --pack-source LocalSources/Escape-The-End --output $stage
```

Исходный lock содержит 147 обязательных зависимостей и хеши 1222 авторских файлов. Полный lock дополнительно закрепляет скачанные файлы и слой интеграции. Этот слой сохраняет параметры мира при открытии для сети, добавляет журналирование сетевых исключений и локализует квестбук. Два авторских сетевых мода исключены из поставки после проверки точных хешей. `e4mc` конфликтует с подключаемым лаунчером e4steam, а Lan Server Properties подменяет штатное окно открытия мира. `options.txt` не входит в список принудительно обновляемых файлов.

## Русский квестбук

Выберите в настройках Minecraft «Русский» и откройте книгу клавишей G. Переведены все 11 глав, группы, заголовок книги и авторские тексты заданий. Названия музыкальных композиций сохраняются в оригинале или приводятся рядом с русским названием. Английский текст используется при выборе English (US) и как запасной для остальных языков. Для игроков с разными языками в одном мире каждый клиент использует свою локаль.

Ручной перевод хранится в `tools/quest-localization/` отдельно от авторского архива. Ключи зависят от главы и точной исходной строки. Подготовка заменяет только видимый текст на языковые ключи FTB Quests и добавляет словари KubeJS. ID квестов, условия, порядок прохождения, награды и формат сохранений не меняются. Файлы локализации и изменённые SNBT перечислены в `launcher/pack-owned.txt`.

При выходе нового авторского архива выполните из корня исходников сборки:

```powershell
python -B tools/localize_quests.py review $authorZip
```

Совпадающие строки в той же главе сохраняют ручной перевод. Добавьте переводы для `missing`, удалите `obsolete` и проверьте совпавшие формулировки, если автор изменил их контекст. Для новой версии сначала снимите клиентскую квитанцию через `prepare.py --client-only`. Если `release_overlay.py review-update` подтверждает совместимость, перенесите её привязку к новому архиву. При изменении квестов снимите полный авторский lock через `prepare.py` без `--pack-source`, используя новую клиентскую квитанцию в `--expect`. Обновите авторские разделы обоих lock-файлов из новых квитанций, сохранив секцию `overlay` полного lock, и закрепите новый SHA256 архива в `tools/overlay.json`. Изменения состава, дескриптора и исключаемых сетевых модов сверяются отдельно.

Выполните `python -B tools/localize_quests.py build $authorZip`, затем `python -B tools/localize_quests.py verify $authorZip`. Если обновились FTB Quests, FTB Library, KubeJS или моды из `tools/quest-item-names.json`, перепроверьте соответствующие подстановки. Обновите URL и контрольную сумму архива в workflow публикации. GitHub Actions сверяет весь авторский квестбук с таблицами и блокирует выпуск при неполном или устаревшем переводе.

## Приёмка и публикация

Пройдите запуск точной версии Forge, создание мира, безопасное появление хоста и гостя на дальних островах Края, журнал заданий, сохранение и повторный вход. В паузе проверьте публикацию одним нажатием, отсутствие промежуточного окна, кнопку «Жалобы», сообщения о локальном порте и готовом Steam-адресе. Повторите в мирах с включёнными и отключёнными командами и проверьте реальную смену времени командой с клиента гостя. Сверьте локальный TCP, собственное Steam-лобби и отдельный прогон двух аккаунтов, если он согласован. Фактический ModList, официальные страницы, превью и QA-квитанции потребуются перед публикацией карточки. [Правила приёмки LANMinecraft](https://github.com/MarkZamore/LANMinecraft/blob/main/tools/ADDING-A-LIBRARY-PACK.md)

Авторская версия с неизменёнными модами дошла до главного меню на Java 17 и Forge 47.4.10. Forge зарегистрировал 150 ID вместе с Minecraft и самим загрузчиком. Сетевой журнал прошёл 14 проверок. В исходном FancyMenu проверены штатные кнопки подключения, режима игры и команд. Интеграция Steam и игровые сценарии проверяются отдельно от этой авторской сборки.

Владелец публикации подтвердил разрешение на этот состав. Уведомления авторов, исходные ссылки и оговорки по лицензиям хранятся в [NOTICE.md](NOTICE.md). Для выпуска используйте `Escape The End` в GitHub Actions. Он воспроизводит состав из закреплённой ревизии, скачивает все публичные файлы для независимой проверки и проверяет чистую установку кодом лаунчера 500.
